# ACE Engine - Another Custom Engine

WIP C++ Game engine using SDL2 and OpenGL

## DISCLAIMER:
This is a project I took on about 4 years ago, starting to learn about 
graphics programming and game engine development, until it overwhelmed me and I abandoned it. 

Since then I learned a LOT about software engineering practices and software development in general, but I never really got the same raw motivation to start over with something like this again. That's why I decided to take over the task of resuming the development of this project.

It has a LOT of design flaws that I'm currently addressing and working, so while it ***technically*** compiles and runs and ***could*** be made into a fully fledged videogame, it is for the best to first try to fix most of these issues, some of which are listed below.

## Current goals:
- Use CMake as build system
- Improve overall project organization and design
- Separate rendering system into front-end and back-end
- Finish implementing entities
- Scripting
- Custom scene format
